# Changelog

## 1.0.0.0

- Initial public release.
- Added four rut-depth presets: Base Game, Default, Medium, and High.
- Added an in-game settings entry with savegame persistence.
- Added multiplayer host/admin synchronization.
- Designed compatibility with Mud System Physics and Use Up Your Tyres.
- Uses FS25's native terrain-deformation system without a per-frame update loop.
